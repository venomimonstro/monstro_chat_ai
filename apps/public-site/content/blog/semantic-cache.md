Похожие вопросы посетителей можно обслуживать из кэша, не вызывая модель повторно.

## Как это работает

Запрос сравнивается с эмбеддингами прошлых ответов. При высоком сходстве возвращается готовый ответ.

## Эффект

Снижение расходов на API провайдеров и стабильная latency при росте трафика.
