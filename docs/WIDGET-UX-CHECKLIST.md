# Widget UX Checklist — Sprint 26

Внутренний чек-лист для QA виджета (20 пунктов). Цель: 20/20 на Chrome, Firefox, Safari (desktop + mobile).

| # | Критерий | Chrome | Firefox | Safari |
|---|----------|--------|---------|--------|
| 1 | Панель фиксированного размера (580×600), не fullscreen | ☐ | ☐ | ☐ |
| 2 | Позиция bottom-right / bottom-left по конфигу | ☐ | ☐ | ☐ |
| 3 | FAQ-sidebar с quick replies, клик отправляет сообщение | ☐ | ☐ | ☐ |
| 4 | Широкие пузыри (max-width ~75%) | ☐ | ☐ | ☐ |
| 5 | Escape закрывает панель | ☐ | ☐ | ☐ |
| 6 | Tab-навигация по кнопкам и полю ввода | ☐ | ☐ | ☐ |
| 7 | Кнопка «прокрутить вниз» при чтении истории | ☐ | ☐ | ☐ |
| 8 | Emoji picker открывается и вставляет символ | ☐ | ☐ | ☐ |

- 375px (iPhone SE)
- 768px (iPad portrait)
- 1024px (iPad landscape / small desktop)
- 1440px (desktop)

Цель: **≥ 95** на демо-странице виджета.
