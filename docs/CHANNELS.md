# Подключение каналов VK и Telegram

## Общие сведения

Входящие сообщения из VK и Telegram проходят через единый pipeline `IChannelAdapter` и обрабатываются тем же AI-оркестратором, что и виджет на сайте. Диалоги попадают в CRM, лиды извлекаются автоматически.

Webhook URL формируется по шаблону:

```
{API_PUBLIC_URL}/api/channels/{telegram|vk}/{widgetKey}/webhook
```

`widgetKey` — уникальный ключ источника (виден в личном кабинете → Источники).

---

## Telegram

### Шаги

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите **Bot Token**.
2. В личном кабинете: **Источники → Добавить → Telegram**.
3. В карточке источника введите Bot Token и нажмите **Подключить бота**.
4. Платформа автоматически вызовет `setWebhook` на ваш API.
5. Напишите боту в Telegram — сообщение появится в CRM как диалог.

### Переменные окружения

| Переменная | Описание |
|------------|----------|
| `API_PUBLIC_URL` | Публичный URL API (например `https://api.example.com`) |

### Проверка

```bash
curl -X POST "https://api.telegram.org/bot<TOKEN>/getWebhookInfo"
```

## ВКонтакте (Callback API)

### Шаги

1. Создайте источник типа **ВКонтакте** в личном кабинете.
2. В настройках сообщества VK: **Управление → Работа с API → Callback API**.
3. Укажите URL webhook: `{API_PUBLIC_URL}/api/channels/vk/{widgetKey}/webhook`
4. Скопируйте **строку подтверждения** и **ключ доступа**.
5. В личном кабинете введите ID группы, ключ и строку подтверждения.
6. В VK включите событие `message_new`.

При первом запросе VK отправит `type: confirmation` — платформа вернёт строку подтверждения автоматически.

### Права ключа

- Сообщения сообщества
- Управление сообществом (для Callback API)

---

## Безопасность

- Bot Token и ключ VK хранятся в `config_json` источника в зашифрованном виде (`CredentialCryptoService`).
- Webhook-эндпоинты публичные; идентификация источника — по `widgetKey` в URL.

---

## Отладка

- Логи API: `ChannelMessageService`, `TelegramChannelAdapter`, `VkChannelAdapter`
- Убедитесь, что источник в статусе **Активен**
- Для Telegram: бот должен получать сообщения (не заблокирован пользователем)
